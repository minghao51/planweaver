# Implementation Summary - 2026-03-26

## Overview
Recent refactoring to streamline PlanWeaver by removing deprecated frontend code and enhancing the testing/monitoring infrastructure.

## Changes

### Removed
- **React frontend** (`frontend/` directory) - replaced with vanilla HTML/JS in `static/`
- **Deprecated scenario files** - `data/scenarios/` directory removed
- **Outdated docs** - `PHASE_4_TASKS.md`, `docs/roadmap.md`

### Testing Infrastructure
- Added `pytest-html` for HTML test reports
- Defined explicit test markers: `integration`, `llm_e2e`, `ui_e2e`
- Auto-load `.env` in `conftest.py` for LLM E2E tests

### Orchestrator Enhancement
- **Critic review fingerprinting** - detects when candidate plans have been modified since last review
  - `_candidate_review_fingerprint()` - generates SHA256 hash of candidate content
  - `_critic_review_stale()` - checks if fingerprint changed
  - `_review_candidate_sync()` - wrapper for sync contexts
- Integrated into: `branch_candidate`, `refine_candidate`, `approve_candidate`, `seed_baseline_candidate`, `add_proposal`

### API
- Static files mounted at root (`/`) with `html=True` for SPA routing

## New Test Files
- `tests/test_observer.py` - Observer/ProbeResult tests
- `tests/test_plan_model.py` - Plan model tests
- `tests/test_probes.py` - Probes tests

## Lint/Type Fixes
- Fixed unused imports in `test_scout.py`, `test_observer.py`, `conftest.py`
- Fixed `Optional[str]` comparison in `test_ui_e2e.py`
